# PeripheralSim — G0 スパイク用のペリフェラル役

Apple Watch を起こす相手役。サービスを 1 つ広告し、ハートビート characteristic を
一定間隔で notify する。**この notify が watchOS の背景起床トリガになる**（設計 §2.1）。

iPhone アプリはまだ無いので、Mac をペリフェラル役にして G0 を測る。
G0 で確かめたいのは Watch 側の挙動なので、相手が Mac でも成立する。

## 使い方

```bash
swift run PeripheralSim
```

初回は Bluetooth の許可を求められる。拒否された場合は
システム設定 → プライバシーとセキュリティ → Bluetooth でターミナルを許可する。

## 対話コマンド

| キー | 動作 | 使いどころ |
|---|---|---|
| `n` | notify を即時 1 回送る | 単発の起床確認 |
| `d` | 接続を切る（サービスを外して戻す） | フェーズ B（切断で予算を消費させる） |
| `i` | 送信間隔を変更する | 予算 5 回/24h を意識した間隔調整 |
| `s` | 送信状況を表示 | 送った数と Watch 側の受信数を突き合わせる |
| `q` | 終了 | |

## ペイロード

12 バイト。Watch 側はこれで取りこぼしと遅延を測る。

| オフセット | 型 | 内容 |
|---|---|---|
| 0 | UInt32 (LE) | 連番。飛びは「届かなかった notify」の数 |
| 4 | UInt64 (LE) | 送信時刻（Unix ミリ秒） |
